# Startup AI Assistant & Evaluation Platform

The capstone of the journey. Assemble everything into one platform a startup can run: configurable AI assistants backed by versioned prompts, an evaluation pipeline that gates every change on correctness and hallucination, full observability that captures latency, token cost, and quality per request, live dashboards over Server-Sent Events, RAG knowledge sources, a LangGraph agent runtime, and a Docker Compose stack plus an AWS deployment runbook. Optimized for trustworthy, observable AI in production.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).
